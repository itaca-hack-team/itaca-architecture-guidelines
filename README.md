# Ejemplo de Proyecto con Contexto Técnico para IA

Esta carpeta demuestra cómo estructurar la documentación técnica mínima viable dentro de un repositorio para guiar a herramientas de IA (Antigravity, Cursor, Copilot, etc.) y evitar alucinaciones o desorden arquitectónico.

## Contenido de `/docs`
1. `01-SCOPE.md`: Define el problema, los 3 flujos críticos del MVP y lo que queda explícitamente fuera de alcance.
2. `02-ARCHITECTURE.md`: Define el stack cerrado, la estructura de carpetas y los diagramas en formato **Mermaid** (Contenedores C2 y Secuencia).
3. `03-API-CONTRACT.md`: Define los tipos TypeScript y endpoints exactos antes de programar.
4. `04-AI-RULES.md`: Establece convenciones y restricciones negativas para el agente de IA.
